# Sky Collector

A one-minute browser game. Catch falling shapes with a basket you move by tap, click, or arrow keys.

## Play

Open [index.html](index.html) in a browser, or download the file and open it locally. No install and no build step.

- Arrow keys or A / D move the basket
- Click, tap, or drag to place it
- Orbs, boxes, gems, and stars are worth more as they get rarer
- You have 60 seconds. Best score is saved in the browser
